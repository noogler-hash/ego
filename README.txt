EGO - Game upload package

Main game: EGO.html
The HTML file is self-contained and includes the game code, the EGO background, and the animated boss sprites.

Assets/Background/ego_background.png is the original background image supplied for this game.
Assets/CC0_Source_Packs contains the original slime, mushroom, goblin, and golem sprite packs used for the bosses. The source packs are included for future editing; the game already embeds the sprites it needs.

The sprite packs are CC0 1.0. The creator notes that the art is AI-assisted. License and notes are included in Assets/CC0_Source_Packs.
